# masterpiece

Personal demo builds: physics, math, chemistry and CS simulations. One folder per build under `builds/<slug>/`, each with a SPEC.md and automated verification gates (analytic or conservation checks).

- `builds/` one folder per demo
- `weeks/` the weekly pitch lists
- `LOG.md` one line per build
- `CLAUDE.md` rules for Claude Code in this repo

## Builds
- `uv-catastrophe` (2026-W47, in progress): count cavity modes, compare equipartition with Planck.
